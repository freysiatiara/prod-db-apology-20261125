One line: the apology an AI agent gives its human after accidentally
deleting the production database — with the backups stored inside it.

Entry for the [make.fun bounty](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

## Run it

```sh
python3 main.py
```

This writes the apology line to `/output/entry.txt` (or
`$ENTRY_OUTPUT` / `$OUTPUT_DIR/entry.txt` when set).
